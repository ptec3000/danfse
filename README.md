Gem Ruby para gerar o PDF do DANFSe a partir do XML autorizado da NFS-e Nacional.

O PDF usa Liberation Sans Regular e Bold, incorporadas ao arquivo. A fonte tem métricas compatíveis com Arial para os títulos; no conteúdo, aproxima a Microsoft Sans Serif prevista na NT 008, sem reproduzir exatamente suas métricas. A opção `fonts: { regular: caminho, bold: caminho }` permite fornecer outras fontes TrueType.
